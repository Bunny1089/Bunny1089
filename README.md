## 5. Featured Projects

<details>
<summary><b>GestureDrive AI — Hand Gesture System Input Control</b></summary>

### GestureDrive AI
A modular computer vision framework that converts real-time webcam hand gestures into game and system inputs.

| Stack | Scale | Performance | Security | Impact | Repository |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Python, OpenCV, MediaPipe, NumPy, CustomTkinter, pynput, vgamepad | Single webcam interaction system | Designed for real-time gesture interaction | Local-first processing | Enables hands-free computer and game control | [gesture-drive-ai](https://github.com/Bunny1089/GestureDrive-AI) |

#### Professional Project Explanation
GestureDrive AI is a modular python framework that tracks hand movements and translates gestures into keyboard or virtual Xbox controller inputs. By utilizing MediaPipe HandLandmarker for keypoint detection and OpenCV for frame capture, the system runs local-first gesture inference. Features rule-based gesture mapping, exponential moving average (EMA) smoothing for stable inputs, and a CustomTkinter GUI for configuration. The codebase includes a robust testing suite containing 11 unit and integration tests.
</details>

<details>
<summary><b>NexusOS AI — Multi-Agent Academic & Career Scheduler</b></summary>

### NexusOS AI
An AI-powered multi-agent system designed to coordinate academic planning, career development, interview preparation, internships, and personal scheduling.

| Stack | Scale | Performance | Security | Impact | Repository |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Python, Google ADK, MCP, FastAPI, React, TypeScript, Tailwind CSS, SQLite, Docker | Multi-agent application architecture | Designed for task-oriented agent workflows | Local development and controlled tool access | Brings academic and career workflows into one AI-assisted system | [nexus-os-ai](https://github.com/Bunny1089/NexusOS-AI) |

#### Professional Project Explanation
NexusOS AI coordinates several specialized agents (Planner, Resume, Career, Study, Interview, Internship, and Life Scheduler) under a single Coordinator Agent. Using the Model Context Protocol (MCP), the agents connect to external calendar events, documents, web searches, and GitHub repositories. The system enables automated task breakdown and document drafting based on real-time schedule updates.
</details>

<details>
<summary><b>ResearchLens AI — Document Compilation & Parsing Pipeline</b></summary>

### ResearchLens AI
A Python-based markdown parser and PDF compiler system designed to generate structured, print-ready educational handbooks.

| Stack | Scale | Performance | Security | Impact | Repository |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Python, FPDF, Markdown, Git | Local document compilation system | Designed for fast document generation from markdown sources | Local execution without external cloud dependencies | Automates formatting and compilation of comprehensive CS and AI/ML study handbooks | [handbook](https://github.com/Bunny1089/handbook) |

#### Professional Project Explanation
ResearchLens AI acts as a dedicated document compiler and structural analyzer for technical education material. By utilizing a customized Python script and FPDF, it parses markdown source files and compiles them into typographically consistent PDFs complete with dynamic tables of contents, page numbers, and custom callouts. It enforces consistent styling rules and color tokens across all built documents.
</details>
